# Operations Analytics & Cloud Data Pipeline

## Project Overview

This project is a realistic operations analytics and cloud data pipeline portfolio project.

It simulates a marketplace/e-commerce business with messy operational data, including customers, products, orders, order items, web events, marketing spend, inventory, returns, and exchange rates.

The goal is to build an end-to-end workflow from raw messy data to cleaned datasets, SQL analytics, KPI reporting, forecasting/predictive modeling, and cloud-style pipeline documentation.

## Business Context

The project represents an operations analytics case study for a fictional marketplace/e-commerce company.

The company wants to answer questions such as:

- How much GMV and revenue are we generating?
- Which product categories perform best?
- Which marketing channels are efficient?
- What is our return rate?
- Are stockouts hurting sales?
- Can we forecast future demand?
- Can we predict returns or repeat purchases?
